# Security

How the Loan Management System meets the security rules in [CLAUDE.md §6](../CLAUDE.md), where each one is implemented, and which test proves it. Known limitations are listed at the end.

**Architecture in one line:** the browser talks only to the Next.js app on Vercel. It proxies `/api/*` to the Express API on Render, which is the only thing that talks to MongoDB Atlas. The frontend route guard is UX only; **every rule is enforced by the API**.

### Frontend

- `proxy.ts` (route guard) verifies the session JWT and **fails closed**: a missing secret or a bad token means anonymous, and the bad cookie is deleted.
- Open redirects are blocked by `getSafeNextPath`: `//host`, `/\host`, absolute URLs and paths the role can't open fall back to the role's home (`route-access.test.ts`).
- Page security headers: `X-Frame-Options: SAMEORIGIN`, `frame-ancestors 'self'`, `nosniff`, Referrer-Policy, Permissions-Policy. The `/api` proxy never runs through a Vercel Function, so uploads aren't capped at 4.5 MB.

**Notes**

1. Express 5's types don't allow a narrowed `req.query` on a route, so list endpoints parse their query string in the controller with the same strict schema. It still runs after `authenticate` and `requireRole`. Endpoints that take no query parameters ignore any that are sent; nothing reads them.

## Known limitations

| Limitation                                                                                       | Why / mitigation                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Shared, published demo credentials** (`Password@123` for every seed account)                   | Required by the assignment. Don't enter real personal data. Rotate the credentials and remove demo data before any real use.                                                                                                                                                                                                                                                      |
| Sign-up reveals whether an email is registered (409)                                             | Unavoidable without email verification; sign-ups are rate-limited (10 per hour per IP).                                                                                                                                                                                                                                                                                           |
| Stateless JWT: logout clears the cookie but a stolen token works until it expires (1 day)        | Short expiry. Server-side revocation is out of scope. `authenticate` reloads the user on every request, so deleted accounts and role changes take effect immediately.                                                                                                                                                                                                             |
| Rate-limit keying depends on `TRUST_PROXY_HOPS`                                                  | It must be measured on the deployed Vercel → Render path (docs/DEPLOYMENT.md, checkpoint B step 5). Someone calling the `*.onrender.com` URL directly has a shorter proxy chain and could spoof `X-Forwarded-For` to dodge the limits. A Vercel-injected secret header would close this; it isn't implemented. Limits are in memory per instance (Render free runs one instance). |
| Atlas network access is `0.0.0.0/0`                                                              | Render's free tier has no static outbound IPs; the database is protected by its password and TLS.                                                                                                                                                                                                                                                                                 |
| Requests without an `Origin` header skip the Origin check                                        | Browsers always send `Origin` on state-changing requests; non-browser clients still need a valid session cookie.                                                                                                                                                                                                                                                                  |
| "One active loan" is per account, not per PAN                                                    | As specified; one person with two accounts could hold two loans.                                                                                                                                                                                                                                                                                                                  |
| A slip replaced in one tab while applying in another can leave a loan pointing at a deleted file | Narrow race; the viewer returns 404. Documented rather than engineered away.                                                                                                                                                                                                                                                                                                      |
| PAN is stored in plain text in MongoDB                                                           | Needed for underwriting; never logged, and masked in every staff response. Encryption at rest is Atlas's.                                                                                                                                                                                                                                                                         |
| Dev-only advisory GHSA-vfj7-8cjw-p6xm (`braces`, via eslint-config-next)                         | Affects only the linter on our own file globs, never runtime input. No fix published yet; Dependabot will propose it.                                                                                                                                                                                                                                                             |
